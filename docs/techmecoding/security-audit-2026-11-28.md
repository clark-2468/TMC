# Security audit, 28 November 2026

The baseline is `bda3f3f46a2` on `main`. GitHub's code-scanning API returned HTTP 403 and the dashboard returned HTTP 404 in the available session. The reported 144 open alerts remain unclassified. The findings below come from a separate source and dependency review. A CodeQL alert export with rule IDs, severity, locations and available analysis metadata is needed to reconcile them.

| Finding | Severity and exposure | Action and residual risk |

| [Emmet image parsing](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr) | High advisory. Inherited, shipped extension. Emmet must process the affected image. An infinite loop can stall the extension host. | Upgrade the parser to 2.0.3 using its supported file API. Type-check, bundle and validate local, data URL and HTTP image handling. Rebuild distributions after review. |
